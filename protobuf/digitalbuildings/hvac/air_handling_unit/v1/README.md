# AirHandlingUnit

Tag for air-handling units. AHUs are devices which handle air distribution (either to a single space or to multiple via ductwork), and they have the capability of handling both return and outside air, in some combination (0% OA, 100% RA; 50% OA, 50% RA; 100% OA, 0% RA, etc.); that is, they can recirculate or ventilate. They are distinct from other devices in key ways: FCUs, which handle only recirculated air; MAUs, which handle only outside air; and DOAS devices, which handle outside and return air, but which do not recirculate air.
