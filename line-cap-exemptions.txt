# Line-cap exemptions for generated protos.
#
# `just cap` holds every .proto under protobuf/ to 200 lines. The files below
# are over it and cannot be brought under: each is a SINGLE message or a
# SINGLE enum, and protobuf can continue neither across a file boundary. Their
# size is set by the ontology's field and variant counts, not by any layout
# choice this repository makes.
#
# The check is bidirectional, which is what stops this list going stale:
#
#   - a .proto over 200 lines that is NOT listed here fails the build. Split
#     it. If it genuinely cannot be split, add it here in the right section.
#   - a .proto listed here that is now UNDER 200 lines also fails the build.
#     Delete its line. An exemption nobody needs is one nobody rechecks.
#
# So a spec bump that grows a message past 200 stops CI until someone looks,
# and one that shrinks a message back under 200 does too. Never add an entry
# for a file that could be split -- that is what the sections below are for.
#
# Order and grouping are maintained by hand; the check ignores both.
